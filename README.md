## 🧠 Mi estrategia

- Trato cada funcionalidad como una operación: **hipótesis, tamaño de la posición y criterio de salida** antes de entrar.
- Si los datos dicen que no, cierro la posición. Sin apego emocional (casi siempre 😅).
- Prefiero muchas iteraciones pequeñas a un *all-in* en la versión 1.0.
- El mejor indicador técnico sigue siendo el feedback de los usuarios.
